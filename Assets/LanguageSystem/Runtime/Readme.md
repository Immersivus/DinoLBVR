### **Language System**  

The **Language System** is designed to manage the languages available in an application.  

To use it, different **Scriptable Objects** must be configured:  

- **Language Config**: Defines the default language.  
- **Languages**: Contains the list of languages available for the application.  

### **Language Objects**  

These objects adapt based on the selected language:  
- **Language Audio Object**  
- **Language Texture Object**  
- **Language Animation Object**  
- **Language Text Object**  
- **Language Video Object**
